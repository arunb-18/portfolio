# Arunachalam Barathidasan — Portfolio

A dependency-free static portfolio, ready for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository and upload the contents of this `portfolio` folder to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main`, and choose `/(root)`.
4. Save. GitHub will publish the site at `https://<your-username>.github.io/<repository-name>/`.

For a site at `https://<your-username>.github.io/`, name the repository `<your-username>.github.io`.

The site has no build command or environment variables. Before publishing, replace the email address or social links in `index.html` if they change.
